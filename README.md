# 文译 · 选中即译

Zotero 10 文献划词翻译插件，提供普通在线、完全离线和 AI 网页三种方式。选中英文并松开鼠标，无需再次点击翻译按钮。

维护账号：`20040819c-ship-it`。MIT 许可，参考来源及致谢见 NOTICE.md。

**0.3.0 是待试装的实验版。自动化检查和普通在线／本地模型示例通过；尚未验证真实 Zotero 中的完整流程及 AI 网站自动发送／读回。**

## 安装及使用

1. 在 Zotero“工具 → 插件 → 齿轮 → 从文件安装插件”选择 `zotero-web-translate-0.3.0.xpi`，覆盖同 ID 的旧版，按提示重启。
2. 打开“工具 → 文译 · 打开 / 收起翻译”。
3. 在“翻译模式”选择需要的方式，确认“选中即翻译”已勾选。
4. 在主窗口 PDF 中拖选英文并松开鼠标，约 450 毫秒后开始翻译。结果在选区旁逐步显示，也可在侧栏查看。

只支持主窗口 PDF 阅读器；独立阅读窗口暂未支持。扫描版 PDF 需先 OCR。翻译需要网络或模型推理时间，自动触发不代表瞬间完成。

## 三种模式

| 模式 | 如何使用 | 原文发到哪里 |
| --- | --- | --- |
| 普通在线翻译（默认） | 无需账号，联网即可尝试 | MyMemory 官方翻译接口 |
| 离线本地翻译 | 首次准备模型后启动本地组件 | 仅本机 `127.0.0.1:27184` |
| AI 网页翻译 | 先在文译侧栏登录 ChatGPT 或 DeepSeek | 所选 AI 网站的聊天记录 |

“无需 AI 账号”不代表不用机器学习：普通在线服务和离线专用翻译模型都属于机器翻译，不需要发送给聊天 AI。

### 普通在线

使用 [MyMemory 官方接口](https://mymemory.translated.net/doc/spec.php)，按 UTF-8 字节拆分长选区，单次片段不超过 450 字节。不使用未经公开说明的聊天接口。

按服务方当前[用量说明](https://mymemory.translated.net/doc/usagelimits.php)，匿名免费额度为每天 5000 字符。达到额度会显示错误，不自动切换其他服务，不上传邮箱或申请密钥。该额度由服务方管理。

### 完全离线

见 [local-engine/README.md](local-engine/README.md)。需要本地组件运行；单独安装 XPI 不包含大型模型。只做英文到中文，使用专用 OPUS-MT 模型。

初次下载需要互联网。正常启动明确禁止远程模型下载，缺少文件时显示错误，不偷偷切换云服务。译文质量和术语准确性需要核对，例如本地示例对 hydrogen bonds 的译法不够理想。

### AI 网页

先在侧栏登录网站，保持网页输入框为空。选中文字后自动填入并尝试发送，在对应的新回答中提取译文。建议先试 ChatGPT；DeepSeek 部分页面的发送按钮可能不能自动识别。

网站改版、验证码、账号额度或登录问题会造成失败，需自行处理。插件不读取密码、不绕过验证码。网页已有草稿时不覆盖。若自动适配失败，可用“复制提示词”手动发送；该备用方式需要点击，不算自动翻译通过。

## 其他行为

- 连续改选时只启动最新尚未发送的请求，已发出的旧请求不能撤回；旧回复不会覆盖新选区。
- 当前会话缓存最近 30 次成功结果，模式和文献不同则分开缓存；不写入磁盘。
- 关闭“选中即翻译”会取消后续自动处理，已发送请求可能继续生成。
- 可修改译文并保存为来源文献下的笔记。独立 PDF 需先创建父条目。
- 插件 ID 与师兄的 AI Web for Zotero 不同，可同时安装；本版与其共同启停的界面行为仍待验收。
- 早期 `@local` ID 的本地试装版需先卸载，避免出现两个文译插件。

## 开发与发布

需要 Node.js 和 Windows PowerShell：

```powershell
npm ci --ignore-scripts
npm test
npm run build
```

XPI 和 SHA-256 输出到 `dist/`。本地组件依赖单独安装，不打包进 XPI。测试含模拟 DOM 和真实本地 HTTP 服务，不代替 Zotero／AI 网站联调。

源码可以作为开发原型上传到 `20040819c-ship-it/zotero-web-translate`；安装包建议通过手动验收后再发预发布版本：

- [ ] 安装升级、禁用、重启无重复入口。
- [ ] 真实 PDF 选中即触发，三种模式各自显示正确结果。
- [ ] 离线组件启动后断网测试成功。
- [ ] AI 网页发送／读回与当前选区对应，无历史回复混入。
- [ ] 改选、缓存、草稿保护、自动开关、笔记保存正常。

保留 LICENSE 和 NOTICE.md，不上传 `node_modules/` 或本地模型缓存。模型权重使用其自身许可，本项目的 MIT 许可不替代模型许可。

`updates.json` 目前保留空列表，避免把尚未验证的实验版自动推送给其他用户。本地改动尚需另行上传 GitHub。
