# 文译 · Web Translate for Zotero

在 Zotero PDF 中选择文字，生成中文翻译提示词，填入侧栏中的 AI 网页。登录网站账号使用，无需 API Key。

维护账号：`20040819c-ship-it`。仓库名：`zotero-web-translate`。

**当前是 0.1.0 原型：已做自动化测试，尚未完成 Zotero 10 内的真人登录和翻译验证。**

## 当前功能

- 选中文字后，浮动工具栏出现“文译 · 翻译选中文字”。
- 原文、翻译方式和提示词可预览、修改。
- 提供 ChatGPT 和 DeepSeek 网页入口；自动填入为实验功能。
- 你在网页上点击发送，译文显示在网页聊天中。
- 自动填入失败时，可复制提示词后在网页粘贴。
- 将网页译文粘贴回插件，保存到来源文献的子笔记。
- 独立插件 ID、菜单和设置，可以与 AI Web for Zotero 同时安装。

本版不提供全文双语 PDF、不自动提取网页答案，也不自动上传整个 PDF。支持范围先限定 Zotero 10 主窗口中的阅读器；独立阅读窗口尚未支持。

## 安装及首次使用

1. 在 Zotero 的“工具 → 插件 → 齿轮 → 从文件安装插件”安装 `zotero-web-translate-0.1.0.xpi`。
2. 打开“工具 → 文译 · 打开 / 收起翻译”。需要更多空间时可先收起师兄插件的侧栏。
3. 在文译侧栏选择网站，在网页中自行登录。两种插件的登录状态可能被 Zotero 共享，勿依赖完全隔离。
4. 在主窗口打开 PDF，拖选一段英文，点击浮动工具栏的“文译 · 翻译选中文字”。
5. 检查原文，点击“生成提示词”。
6. 点击“填入网页”，检查网页输入框，再在网页上点击发送。
7. 若自动填入失败，点击“复制提示词”，在网页输入框粘贴、发送。
8. 如需保存，复制网页中的译文，粘贴到文译“译文”框，点击“保存为文献笔记”。

选中文字后只提取原文到本地表单；点击“填入网页”或自己粘贴时，文字进入网站页面；点击网页发送后由所选服务处理。网站的隐私政策、账号额度和模型能力适用。插件不读取密码，不绕过验证码，不调用未公开聊天 API。

## 常见情况

- **没有按钮**：确认 PDF 文字可以被选中；扫描版 PDF 需先做 OCR。确认插件启用并重新打开 PDF。
- **找不到输入框**：先在网页登录、等加载完成；网站改版后使用复制粘贴的备用方式。
- **网页已有草稿**：自动填入会停止，避免覆盖；先自行处理草稿。
- **独立 PDF 不能保存笔记**：在文献库为 PDF 创建父条目，再从该 PDF 选中文字。独立 PDF 没有父文献时本版不保存笔记。
- **译文没自动出现在翻译框**：本版需要从网页手动复制译文。自动抓取尚未实现。
- **自动更新**：更新源位于本仓库的 `updates.json`，当前列表为空，尚不提供新版本。仓库公开后更新源才能访问。

## 开发与构建（Windows）

需要 Node.js 和系统自带的 Windows PowerShell。

```powershell
npm ci --ignore-scripts
npm test
npm run build
```

安装包输出到 `dist/`，附带 SHA-256 文件。测试使用模拟 DOM，不代表真实网站或 Zotero 的联调通过。
